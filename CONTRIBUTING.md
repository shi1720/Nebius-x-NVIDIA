# Contributing

Use synthetic records in tests and examples. Never commit secrets or real recall evidence.

Before a pull request, run `npm run typecheck`, `npm test`, `npm run test:quota`, and `npm run build`. Run `npm run test:api` against local development after changing authentication, persistence, uploads or review routes. A domain change should include a counterexample that fails before the fix.

Keep AI proposals separate from approved facts, preserve uncertainty, and retain source evidence when changing a relationship. Do not rename outside-path records to safe or cleared. Do not mix kg with finished-unit counts. Changes to provider behavior require explicit live validation; mock test success must not be represented as real model accuracy.

Format authored TypeScript and Markdown with Prettier. Preserve vendored UI primitives and third-party notices. Once deployed, migration files are immutable; append new migrations.
