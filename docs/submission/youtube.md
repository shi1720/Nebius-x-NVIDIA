## Description

A supplier recalls one ingredient lot. Which products did it reach, who received them, and what evidence is still missing?

RecallRoom is an evidence-backed investigation workspace for small food manufacturers and co-packers. This demo follows a fictional peanut-butter recall through batch records and customer shipments. It shows confirmed exposure, an ambiguous cookie batch, a documented review decision, and an exportable response packet.
