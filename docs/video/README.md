# RecallRoom recorded walkthrough

- Watch: https://recallroom.web.app/demo.html
- MP4: https://recallroom.web.app/demo/RecallRoom-demo.mp4
- Captions: https://recallroom.web.app/demo/RecallRoom-captions.srt
- Duration: 145.06 seconds, 1920 by 1080, H.264 video with AAC audio.

The walkthrough uses actual captured application screens. It is an edited sequence of product states, with a neutral synthetic voice generated using OpenAI TTS and visible captions. It does not imitate Shivam Gupta's voice. All records are fictional.

Live NVIDIA inference on Nebius remains unverified. The narration and description disclose this limitation. The video must be updated with a real provider run before representing it as a completed hackathon inference demonstration.

The source narration is in `narration-segments.json`. `scripts/generate-narration.py`, `scripts/caption-video.py`, and `scripts/render-demo.py` create audio, align captions, and compose the recording. Local working media is kept in ignored `outputs/video`. The finished MP4 and SRT are versioned in `public/demo`.

YouTube publication is awaiting action-time confirmation of the upload screen's Terms of Service acknowledgement. The requested title and description are in `docs/submission/youtube.md`.
